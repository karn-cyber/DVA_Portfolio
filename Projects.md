## Project Descriptions

### 1. Short Form Attention Analytics

This project focuses on analyzing user engagement with short-form content such as reels or short videos. It aims to understand how attention spans vary across users and identify patterns in content consumption.

Key aspects of the project include:
- Cleaning and preprocessing raw user interaction data  
- Performing Exploratory Data Analysis (EDA) to uncover engagement trends  
- Measuring important metrics like watch time, retention rate, and drop-off points  
- Visualizing attention patterns to generate actionable insights  

The project helps in understanding how users consume bite-sized content and provides insights that can be useful for content creators and platform optimization.

---

### 2. Netflix-Style User Behavior Dataset

This project simulates and analyzes user behavior on a streaming platform similar to Netflix. It is designed to study how users interact with long-form content and how their viewing habits can be leveraged for better recommendations.

Key aspects of the project include:
- Working with a structured dataset representing user viewing behavior  
- Data cleaning and transformation for analysis  
- Analyzing user preferences, watch history, and genre trends  
- Identifying behavioral patterns such as binge-watching and session activity  

The insights derived from this project are useful for improving recommendation systems, enhancing user experience, and driving content strategy decisions.
