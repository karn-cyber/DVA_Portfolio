## Project Details

### Short Form Attention Analytics

**Overview:**  
This project analyzes how users engage with short-form content such as reels and short videos, focusing on attention span, retention, and engagement behavior.

**Key Highlights:**
- Data cleaning and preprocessing of user interaction datasets  
- Exploratory Data Analysis (EDA) to identify engagement patterns  
- Analysis of watch time, retention rates, and drop-offs  
- Visualization of attention trends for actionable insights  

**Impact:**  
Helps understand modern short-form content consumption and optimize content strategies for higher engagement.

---

### Netflix-Style User Behavior Dataset

**Overview:**  
This project explores user behavior on a streaming platform similar to Netflix, focusing on viewing habits, preferences, and content trends.

**Key Highlights:**
- Data cleaning and structuring of user behavior data  
- Analysis of watch history, genre preferences, and session patterns  
- Identification of binge-watching behavior and engagement trends  
- Insight generation for recommendation systems  

**Impact:**  
Supports data-driven decision-making for improving recommendation engines and enhancing user experience.
